This page answers
What is being built next for his running?
Answer
What each of his high-speed runs was for. It is not in this report yet, and no F03 numbers are shown for it.
What it will answer

For each run above 19.8 km/h: was it a recovery run, a pressing run, an off-ball run in possession, or a run with the ball?

What we are building

Possession state for every second, so each run is tagged in or out of possession. A run-purpose model that reads the run against the ball, teammates and the back line. Carrier attribution, so runs with the ball are credited to the right player.

What we are not saying
  • This is not a finding. It moves into the drill-by-drill view once its outputs agree with coach-labelled clips.
